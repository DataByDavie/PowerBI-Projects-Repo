# 📊 Power BI Data Analytics Project
### Data Technician Bootcamp | Interactive Reporting & Data Storytelling

## 🚀 Project Overview

As part of my **Data Technician Bootcamp**, I completed a Power BI project focused on transforming raw retail and sales data into meaningful business insights. The project involved data extraction, transformation, and modelling using **Power Query**, creating **DAX calculations**, and building interactive dashboards that enable users to explore data through dynamic reports and visualisations. Based on work completed in Data_Technician_Workbook_Week_2_ PowerBI_Only.docx. 【1-a015e7】

The primary goal was to develop professional reports that support data-driven decision-making through clear, engaging, and interactive data storytelling.

## 📖 Data Storytelling Approach

A key focus of this project was turning complex datasets into a clear narrative that decision-makers could easily understand.

The dashboards were designed to:

### 1️⃣ Overview
Provide an immediate view of key business metrics

### 2️⃣ Exploration
Allow users to interact with the data through filters and slicers

### 3️⃣ Analysis
Highlight trends, patterns, and performance drivers

### 4️⃣ Action
Support informed business decisions through visual insights

By combining multiple visualisations into interactive reports, users can quickly move from high-level summaries to detailed analysis.
